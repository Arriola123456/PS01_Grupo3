# PS01_Grupo3

**Link del video explicativo:** https://drive.google.com/drive/folders/1T1ov99ZHqPOhq5Qp_p7k56zupslqnpYd?usp=sharing

Entregables del Problem Set 01 del curso de Macroeconomía Internacional (Universidad del Pacífico, semestre 2026-I).

## Estructura del repositorio

- `codigo/` — Notebooks de Python con el desarrollo de la Parte V del problem set.
  - `PS01_analisis.ipynb` — **Bloque A** (preguntas 22 y 23): descarga de datos del Banco Mundial vía `wbgapi`, aplicación del filtro Hodrick-Prescott y evaluación de las regularidades empíricas R2–R6 para los siete países asignados.
  - `PS01_simulacion.ipynb` — **Bloque B** (preguntas 24, 25 y 26): simulación de una economía pequeña y abierta ante shocks de productividad, análisis de sensibilidad de parámetros y calibración del país asignado contrastada con la literatura.
  - `datos/` — Carpeta para datos auxiliares utilizados por los notebooks.
- `entregable/` — Documentos finales del grupo.
  - `PS01_Grupo3.pdf` — Resolución integral del problem set (Partes I a V).
  - `declaración_IA.pdf` — Declaración sobre el uso de herramientas de IA.
